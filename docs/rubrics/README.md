# Per-artifact quality rubrics

The "what good looks like" bar for each pipeline artifact — the documentation-based stand-in for a
worked example (no proprietary migration is shipped in this repo). Use them in enablement and as
self-checks.

- `overview.rubric.md` — Solution Architect output
- `plan.rubric.md` — Implementation Planner output
- spec review bar — see `skills/spec-review-checklist/SKILL.md` (it's the gate's checklist)
